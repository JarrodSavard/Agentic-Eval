## Design Context

### Users

Software engineering hiring teams reviewing Jarrod Savard�s portfolio, and Jarrod demonstrating real model behavior. Readers should understand the experiment without knowing agent tooling.

### Brand Personality

Restrained, precise, approachable. The user approved a restrained rental booking board and requested clearer explanations of what is actually happening.

### Aesthetic Direction

Retain the existing light paper, ink, green and amber palette and Archivo typography. Use an editorial sequence with clear task, action and consequence rather than extra dashboard decoration.

### Design Principles

- Explain the assignment before showing metrics.
- Describe observable actions; do not invent model thoughts.
- Distinguish what the model saw from the actual environment state.
- Keep technical evidence accessible through progressive disclosure.
- Preserve honest outcomes, provenance, mobile readability and keyboard access.

Use everyday rental language, named customers, obvious car names and calendar dates. Avoid internal identifiers in primary explanations.
