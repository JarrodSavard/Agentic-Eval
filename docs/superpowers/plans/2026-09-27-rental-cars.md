# Road Test implementation

The user chose rental cars to make the entire application understandable to an everyday audience and asked to remove the prior domain completely.

- Customers need a car with a child seat or luggage space on an allowed October date.
- Keep 24 paired cases across site failures, unavailable cars and missing booking confirmations.
- Use car-specific model prompts, tools, contracts and independent booking checks, all version 2.0.
- Use plain-language labels, calendar dates, named customers and cars throughout.
- Remove superseded examples and rename the Python package and CLI to roadtest.
- Verify offline with property, contract, integration and browser tests.
- Record both Luna models against the same request under the existing $0.50 budget; publish every attempt.

The data is fictional; no real bookings, payments or customer information are involved.
